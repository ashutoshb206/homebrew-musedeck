# Homebrew Tap for MuseDeck 🍺

Official Homebrew Cask tap for **[MuseDeck]** — A floating liquid-glass desktop widget for macOS.

---

## ⚡ Quick Installation

Install MuseDeck with a single command in your terminal:

```bash
brew install ashutoshb206/musedeck/musedeck
```

Or add the tap first:

```bash
brew tap ashutoshb206/musedeck
brew install musedeck
```

---

## 🔄 Updating MuseDeck

To update MuseDeck to the latest release:

```bash
brew upgrade musedeck
```
